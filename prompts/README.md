# Prompts do Projeto

Esta pasta concentra prompts reutilizáveis para descoberta, análise, arquitetura, implementação e revisão.

## Princípio

Prompts devem apontar para o contexto versionado no repositório em vez de repetir grandes blocos de informação.

Exemplo de orientação para um agente:

> Leia `AGENTS.md`, `docs/index.md` e a documentação relacionada à tarefa. Analise o estado atual antes de propor mudanças. Não substitua fatos por suposições. Faça alterações incrementais e atualize a documentação afetada.

## Categorias previstas

- descoberta do problema;
- análise de processos;
- produto e requisitos;
- arquitetura;
- desenvolvimento;
- segurança/compliance;
- testes e validação;
- apresentação do MVP.
