# Registro de Decisões

Use esta pasta para registrar decisões relevantes de produto, arquitetura, integração, segurança e operação.

## Convenção sugerida

```text
ADR-0001-titulo-da-decisao.md
ADR-0002-titulo-da-decisao.md
```

Cada decisão deve conter:

- contexto;
- problema;
- decisão;
- alternativas consideradas;
- consequências;
- status;
- data.
